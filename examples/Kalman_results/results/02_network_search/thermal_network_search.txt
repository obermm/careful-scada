THERMAL NETWORK SEARCH - both main bearings, CARE Wind Farm B (healthy datasets 2, 21, 52, 74, 82, 83)
=====================================================================================================
Model   : experiments/network_search.py (library KalmanThermalForecaster network, free-run: NO bearing sensor
          assimilated; bearings set to their measurement at each sequence start, latent nodes to steady state).
Fit     : per dataset, output-error (MSE of both bearings), 800 Adam steps, 7-day chunks, 2 seeds (best train loss).
Metrics : RMSE [K], mean over 6 datasets and both bearings.
          val  = last 25 % of each train part (fit on the first 75 %)  -> used for selection
          test = CARE test part (same fit)                              -> reported only
Notation: edges a-b (k_ab, k_ba per state-state edge; 1 rate per state-boundary edge); sources s>n heat n
          (s2 = squared, -s = cooling, negative gain); flags c = const heat per bearing, g = gamma*(T_out-10).
          mb1/mb2 main bearings (states), out outside, gb1..4 gearbox bearings, oil gearbox oil, gen1/2 gen.
          bearings (observed boundaries); P power, rot rotor speed, grpm gen speed, ws wind speed 1, pitch.
          Any other node name (nac, hub, hous, ...) is a latent node.
npar    : physics parameters (noise parameters irrelevant in free run).
Raw results: results/02_network_search/raw/*.jsonl (per dataset/seed), greedy traces *_trace.txt.
